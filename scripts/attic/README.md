# scripts/attic

Scripts and fixtures that nothing executable runs: not a `package.json`
script, not a workflow under `.github/`, not an import, disk read or spawn
from any script, config or test. Withheld, never deleted (`PROJECT-KNOWLEDGE`
§3): payload stays on disk, git keeps it reversible, and every withholding
states a reason. Recomputed 2026-10-05 for the architect critique's R6.

Contents are untouched. Relative imports resolve from the original location,
so restore a file with `git mv scripts/attic/<name> scripts/<name>` (for
`jev-eval/*`, back to `scripts/`) before running it. Mentions in generated
file headers (`GENERATED by scripts/<name>`) and dated records are provenance
and were left as written.
