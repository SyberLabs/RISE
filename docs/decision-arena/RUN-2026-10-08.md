## What the run shows

Every number below is for run 1. Both deciders are deterministic: all three
runs gave the same answer for every case and control (89 of 89 for each), so
the repeats add no information.

**Agreement with author-written expectations** (49 explicit checks across 39
cases, admitted decisions; raw decisions give the same numbers):

| Decider | Agreement | 95% Wilson interval | 95% case-cluster bootstrap |
|---|---|---|---|
| `rules` | 41 / 49 (0.84) | 0.71 to 0.91 | 0.74 to 0.93 |
| `rules-floor` | 12 / 49 (0.24) | 0.15 to 0.38 | 0.07 to 0.44 |

**Contrast pairs** (19 pairs in which two cases should differ):
`rules` 18 / 19 (95% Wilson 0.75 to 0.99), `rules-floor` 0 / 19 (0 to 0.17).

**Difference** (`rules` minus `rules-floor`, explicit agreement, paired
case-cluster bootstrap over 39 shared cases): 0.59, 95% interval 0.38 to
0.80. The interval excludes zero (`withinNoise: false`). It shows only that
matching words in the request agrees with these authored expectations more
often than always taking the first option. The cases were written and tuned
by RISE's authors, and their wording may favour word overlap. These numbers
say nothing about any model.

**Out-of-menu answers:** 0 of 267 results for each decider. There were no
refusals and no missing answers, and every result was admitted.

**Latency:** median 0 ms and 95th percentile 0 ms for both deciders. The
slowest of the 534 calls took 2 ms. The time is local computation only, with
no network.

**Cost:** $0. Neither decider calls a model.

**Calibration:** none. The deciders that ran report no probabilities or
confidence, so all 147 expected-question rows were skipped. The controls stay
sealed. Even when the seed is revealed, they test only whether a decider puts
the stated odds on the stated options, and these deciders give no odds.
