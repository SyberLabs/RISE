# Directory screenshots

The five images for RISE's listing in Anthropic's connector directory, each with the prompt to paste beside it in the submission portal. The directory asks for PNG, at least 1000 px wide, 3 to 5 images, cropped to the app's response without the prompt, a prompt given separately for each, and no video or GIF (https://claude.com/docs/connectors/building/submission, read 2026-10-09).

How they were made, 2026-10-09, on `main` at `e3dd1b97`: the production build (`npx vite build`) served by `vite preview`; the self-contained card (`cardHtml`, `src/live/hosts/mcp-card.js`) in a stand-in host page that does what `e2e/live-mcp.spec.js` does (the MCP Apps handshake, the tool input, then the Worker's own `handleMcp` admitting the Current and its result handed to the card); Playwright Chromium. The card is 760 CSS px wide and 502 tall, the height it asks a host for at that width (`LiveHost.js`; the 760 px row of the sizing table in [the embed stage decision](../../product/discussions/2026-10-05-embed-stage-decision.md)). Device scale factor 1.5, so each PNG is 1140 × 753. Each image is the card's frame alone (`locator.screenshot()` on the frame), taken with the pointer just moved over the card so the bar is showing. The device voice is a silent stand-in that reports one installed voice, so the card paces the words as a voice would and shows no "no voice" mark. The host theme was dark; the card does not follow the host's theme (it keeps the reading's own ground), so there is no light variant to take.
