RISE Figure Kit

Four kinds of picture RISE draws with its own code. The model supplies only the data, so labels cannot collide and nothing appears that the data does not name. Each figure below is shown exactly as a reading shows one: an image on the reading's ground.

Accent marks what changed. One element per figure takes the reading's accent: the bar after the change, the new step, the moved control. Everything else is the words' ink at reduced strength.

Hairlines, not boxes. Structure is drawn in 1.5-unit lines at a third of the ink. Shapes carry no heavy outlines; columns are divided by rules instead of boxed.

Type. Titles in a serif, labels in the system sans, at sizes that stay at least 12 px on a 390 px phone. A figure is an image, so it cannot load RISE's own faces; it uses the reader's own serif and sans.

Numbers come only from the data. The kit prints a value it was given and computes nothing new, so the check that every number traces to a pull request still holds.
